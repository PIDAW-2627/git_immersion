lab 6 Preparar cambios

Objetivos

  • Aprender a preparar cambios (staging) para futuros commits

Añade los cambios

Ahora dile a git que prepare los cambios. Comprueba el estado.

Ejecuta:

git add hello.py
git status

Deberías ver…

Salida:

$ git add hello.py
$ git status
On branch main
Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
	modified:   hello.py

El cambio en el archivo hello.py se ha preparado. Esto significa que git ya conoce el cambio, pero este todavía no se ha registrado de forma permanente en el repositorio. La próxima operación de commit incluirá los cambios preparados.

Si al final decides que no quieres hacer commit de ese cambio, el comando status te recuerda que puedes usar el comando git restore para sacar ese cambio del área de preparación (staging).
