lab 20 Mover ficheros

Objetivos

  • Aprender a mover un fichero dentro de un repositorio.

Mueve el fichero hello.py a un directorio lib.

Ahora vamos a ir construyendo la estructura de nuestro pequeño repositorio. Movamos el programa a un directorio lib.

Ejecuta:

mkdir lib
git mv hello.py lib
git status

Salida:

$ mkdir lib
$ git mv hello.py lib
$ git status
On branch main
Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
	renamed:    hello.py -> lib/hello.py

Al usar git para hacer el movimiento, le informamos de 2 cosas

  1. Que el fichero hello.py se ha eliminado.
  2. Que el fichero lib/hello.py se ha creado.

Ambos datos se añaden de inmediato al área de preparación y quedan listos para confirmarse con un commit. El comando git status indica que el fichero se ha movido.

Otra forma de mover ficheros

Una de las ventajas de git es que puedes olvidarte del control de versiones hasta el momento en que estés listo para empezar a hacer commit del código. ¿Qué pasaría si usáramos el comando del sistema operativo para mover el fichero en lugar del comando de git?

Resulta que el siguiente conjunto de comandos es equivalente a lo que acabamos de hacer. Supone algo más de trabajo, pero el resultado es el mismo.

Podríamos haber hecho:

mkdir lib
mv hello.py lib
git add lib/hello.py
git rm hello.py

Haz commit del nuevo directorio

Hagamos commit de este movimiento.

Ejecuta:

git commit -m "Moved hello.py to lib"
