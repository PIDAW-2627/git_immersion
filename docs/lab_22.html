lab 22 Interioridades de Git:
El directorio .git

Objetivos

  • Conocer la estructura del directorio .git

El directorio .git

Es hora de explorar un poco. Primero, desde el directorio raíz de tu proyecto…

Ejecuta:

ls -C .git

Salida:

$ ls -C .git
COMMIT_EDITMSG	ORIG_HEAD  config	hooks  info  objects
HEAD		branches   description	index  logs  refs

Este es el directorio mágico donde se guardan todas las “cosas” de git. Echemos un vistazo al directorio objects.

El almacén de objetos

Ejecuta:

ls -C .git/objects

Salida:

$ ls -C .git/objects
13  31	51  56	6c  83	8a  9e	ab  b6	d0  d6	df  e9	info
19  45	52  5d	78  86	9c  a8	b3  c7	d2  dd	e5  ec	pack

Deberías ver un montón de directorios con nombres de 2 letras. Los nombres de los directorios son las dos primeras letras del hash sha1 del objeto almacenado en git.

Más a fondo en el almacén de objetos

Ejecuta:

ls -C .git/objects/<dir>

Salida:

$ ls -C .git/objects/13
956843b171c232495bc238e175faee03c12264

Mira dentro de uno de los directorios de dos letras. Deberías ver algunos archivos con nombres de 38 caracteres. Son los archivos que contienen los objetos almacenados en git. Están comprimidos y codificados, así que mirar su contenido directamente no sirve de mucho, pero enseguida los examinaremos más de cerca.

El archivo de configuración

Ejecuta:

cat .git/config

Salida:

$ cat .git/config
[core]
	repositoryformatversion = 0
	filemode = true
	bare = false
	logallrefupdates = true
[user]
	name = Jim Weirich
	email = jim (at) edgecase.com

Este es un archivo de configuración específico del proyecto. Las entradas de configuración que pongas aquí sobrescriben las del archivo .gitconfig de tu directorio personal, al menos para este proyecto.

Ramas y etiquetas

Ejecuta:

ls .git/refs
ls .git/refs/heads
ls .git/refs/tags
cat .git/refs/tags/v1

Salida:

$ ls .git/refs
heads
tags
$ ls .git/refs/heads
main
$ ls .git/refs/tags
v1
v1-beta
$ cat .git/refs/tags/v1
d099bc1f8b74dbf57a307e7077041604456e4c82

Deberías reconocer los archivos del subdirectorio tags. Cada archivo corresponde a una etiqueta que creaste antes con el comando git tag. Su contenido es simplemente el hash del commit asociado a la etiqueta.

El directorio heads es parecido, pero se usa para las ramas en lugar de para las etiquetas. De momento solo tenemos una rama, así que lo único que verás en este directorio es main.

El archivo HEAD

Ejecuta:

cat .git/HEAD

Salida:

$ cat .git/HEAD
ref: refs/heads/main

El archivo HEAD contiene una referencia a la rama actual. En este momento debería ser una referencia a main.
