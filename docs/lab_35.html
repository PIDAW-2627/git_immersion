lab 35 Fusionar de vuelta en main

Objetivos

  • Hemos mantenido nuestra rama greet al día con main (mediante rebase); ahora vamos a fusionar los cambios de greet de vuelta en la rama main.

Fusionar greet en main

Ejecuta:

git checkout main
git merge greet

Salida:

$ git checkout main
Switched to branch 'main'
$
$ git merge greet
Updating ab4b7c3..8d83be7
Fast-forward
 lib/greeter.py | 6 ++++++
 lib/hello.py   | 6 ++++--
 main.py        | 5 +++--
 3 files changed, 13 insertions(+), 4 deletions(-)
 create mode 100644 lib/greeter.py

Como la cabeza de main es un ancestro directo de la cabeza de la rama greet, git puede hacer una fusión fast-forward (avance rápido). Al hacer fast-forward, el puntero de la rama simplemente avanza para apuntar al mismo commit que la rama greet.

En una fusión fast-forward nunca habrá conflictos.
