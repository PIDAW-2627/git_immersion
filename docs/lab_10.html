lab 10 Historial

Objetivos

  • Aprender a ver el historial del proyecto.

Obtener una lista de los cambios que se han hecho es la función del comando git log.

Ejecuta:

git log

Deberías ver…

Salida:

$ git log
commit d099bc1f8b74dbf57a307e7077041604456e4c82
Author: Jim Weirich <jim (at) edgecase.com>
Date:   Mon Sep 28 10:00:26 2026 +0000

    Added a comment

commit 195f3156ecbb07f5d05122d7d3ee05a0b17c6510
Author: Jim Weirich <jim (at) edgecase.com>
Date:   Mon Sep 28 10:00:26 2026 +0000

    Added a default value

commit 9c35f1aa26d0f6ba2e7687f909b9e967ca88afe4
Author: Jim Weirich <jim (at) edgecase.com>
Date:   Mon Sep 28 10:00:26 2026 +0000

    Using sys.argv

commit b30d4197c4d0dab697b8f0b2be7ebd6a79e2a4a9
Author: Jim Weirich <jim (at) edgecase.com>
Date:   Mon Sep 28 10:00:26 2026 +0000

    First Commit

Aquí tienes la lista de los cuatro commits que hemos hecho en el repositorio hasta ahora.

Historial en una línea

Tienes mucho control sobre lo que muestra exactamente el comando log. A mí me gusta el formato de una sola línea:

Ejecuta:

git log --pretty=oneline

Deberías ver…

Salida:

$ git log --pretty=oneline
d099bc1f8b74dbf57a307e7077041604456e4c82 Added a comment
195f3156ecbb07f5d05122d7d3ee05a0b17c6510 Added a default value
9c35f1aa26d0f6ba2e7687f909b9e967ca88afe4 Using sys.argv
b30d4197c4d0dab697b8f0b2be7ebd6a79e2a4a9 First Commit

Controlar qué entradas se muestran

Hay muchas opciones para seleccionar qué entradas se muestran en el log. Prueba con las siguientes opciones:

git log --pretty=oneline --max-count=2
git log --pretty=oneline --since='5 minutes ago'
git log --pretty=oneline --until='5 minutes ago'
git log --pretty=oneline --author=<your name>
git log --pretty=oneline --all

Consulta man git-log para ver todos los detalles.

Rizando el rizo

Esto es lo que uso yo para revisar los cambios hechos en la última semana. Añado --author=jim si solo quiero ver los cambios que he hecho yo.

git log --all --pretty=format:'%h %cd %s (%an)' --since='7 days ago'

El formato de log definitivo

Con el tiempo, he decidido que me gusta el siguiente formato de log para la mayor parte de mi trabajo.

Ejecuta:

git log --pretty=format:'%h %ad | %s%d [%an]' --graph --date=short

Tiene este aspecto:

Salida:

$ git log --pretty=format:'%h %ad | %s%d [%an]' --graph --date=short
* d099bc1 2026-09-28 | Added a comment (HEAD -> main) [Jim Weirich]
* 195f315 2026-09-28 | Added a default value [Jim Weirich]
* 9c35f1a 2026-09-28 | Using sys.argv [Jim Weirich]
* b30d419 2026-09-28 | First Commit [Jim Weirich]

Veámoslo en detalle:

  • --pretty=format:"..." define el formato de la salida.
  • %h es el hash abreviado del commit
  • %ad es la fecha del autor
  • %s es el comentario
  • %d son las decoraciones de ese commit (p. ej., cabezas de rama o etiquetas)
  • %an es el nombre del autor
  • --graph indica a git que muestre el árbol de commits como un gráfico ASCII
  • --date=short mantiene el formato de fecha bonito y corto

Es mucho que escribir cada vez que quieras ver el log. Por suerte, en el próximo lab aprenderemos a usar los alias de git.

Otras herramientas

Tanto gitx (para Mac) como gitk (cualquier plataforma) son útiles para explorar el historial del log.
