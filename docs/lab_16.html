lab 16 Deshacer cambios confirmados

Objetivos

  • Aprender a revertir cambios que ya se han confirmado en un repositorio local.

Deshacer commits

A veces te das cuenta de que un cambio que ya has confirmado no era correcto y quieres deshacer ese commit. Hay varias formas de resolver este problema, y la que vamos a usar en este lab es siempre segura.

Básicamente, desharemos el commit creando un nuevo commit que invierte los cambios no deseados.

Modifica el fichero y haz commit.

Cambia el fichero hello.py por lo siguiente.

hello.py

import sys

# This is an unwanted but committed change
name = sys.argv[1] if len(sys.argv) > 1 else "World"

print(f"Hello, {name}!")

Ejecuta:

git add hello.py
git commit -m "Oops, we didn't want this commit"

Crea un commit de reversión

Para deshacer un cambio confirmado, necesitamos generar un commit que elimine los cambios introducidos por el commit no deseado.

Ejecuta:

git revert HEAD

Esto te abrirá el editor. Puedes editar el mensaje de commit por defecto o dejarlo tal cual. Guarda y cierra el fichero. Deberías ver…

Salida:

$ git revert HEAD --no-edit
[main a9bf330] Revert "Oops, we didn't want this commit"
 Date: Mon Sep 28 10:10:42 2026 +0000
 1 file changed, 1 insertion(+), 1 deletion(-)

Como estábamos deshaciendo el último commit que hicimos, pudimos usar HEAD como argumento de revert. Podemos revertir cualquier commit anterior del historial simplemente indicando su valor hash.

Nota: Puedes ignorar el --no-edit que aparece en la salida. Era necesario para generar la salida sin abrir el editor.

Revisa el log

Al revisar el log se ven tanto el commit no deseado como el de reversión en nuestro repositorio.

Ejecuta:

git hist

Salida:

$ git hist
* a9bf330 2026-09-28 | Revert "Oops, we didn't want this commit" (HEAD -> main) [Jim Weirich]
* f9c42ca 2026-09-28 | Oops, we didn't want this commit [Jim Weirich]
* 5870e0e 2026-09-28 | Added a comment (tag: v1) [Jim Weirich]
* 15d9d4e 2026-09-28 | Added a default value (tag: v1-beta) [Jim Weirich]
* b66c896 2026-09-28 | Using sys.argv [Jim Weirich]
* 4387add 2026-09-28 | First Commit [Jim Weirich]

Esta técnica funciona con cualquier commit (aunque puede que tengas que resolver conflictos). Es segura incluso en ramas que se comparten públicamente en repositorios remotos.
