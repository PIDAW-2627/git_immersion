lab 5 Hacer cambios

Objetivos

  • Aprender a vigilar el estado del directorio de trabajo

Modifica el programa “Hello, World”.

Es hora de modificar nuestro programa hello para que reciba un argumento desde la línea de comandos. Cambia el archivo para que quede así:

hello.py

import sys

print(f"Hello, {sys.argv[1]}!")

Comprueba el estado

Ahora comprueba el estado del directorio de trabajo.

Ejecuta:

git status

Deberías ver…

Salida:

$ git status
On branch main
Changes not staged for commit:
  (use "git add <file>..." to update what will be committed)
  (use "git restore <file>..." to discard changes in working directory)
	modified:   hello.py

no changes added to commit (use "git add" and/or "git commit -a")

Lo primero que hay que observar es que git sabe que el archivo hello.py ha sido modificado, pero todavía no se le ha indicado a git que registre estos cambios.

Fíjate también en que el mensaje de estado te da pistas sobre qué tienes que hacer a continuación. Si quieres añadir estos cambios al repositorio, usa el comando git add. Si no, puedes usar el comando git restore para descartar los cambios.
