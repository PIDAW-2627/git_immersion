lab 23 Interioridades de Git:
Trabajar directamente con los objetos de Git

Objetivos

  • Explorar la estructura del almacén de objetos
  • Aprender a usar los hashes SHA1 para encontrar contenido en el repositorio

Ahora vamos a usar algunas herramientas para examinar directamente los objetos de git.

Encontrar el último commit

Ejecuta:

git hist --max-count=1

Esto debería mostrar el último commit hecho en el repositorio. Es probable que el hash SHA1 de tu sistema sea distinto del mío, pero deberías ver algo parecido a esto.

Salida:

$ git hist --max-count=1
* 438b620 2026-09-28 | Added main.py. (HEAD -> main) [Jim Weirich]

Volcar el último commit

Usando el hash SHA1 del commit mostrado arriba…

Ejecuta:

git cat-file -t <hash>
git cat-file -p <hash>

Esta es mi salida…

Salida:

$ git cat-file -t 438b620
commit
$ git cat-file -p 438b620
tree 45e0479d7bc1b23aff1469f636914e9dd07f58a7
parent 77dc242ec1e77fb5942a78a189dc70cf70d9dca2
author Jim Weirich <jim (at) edgecase.com> 1790590242 +0000
committer Jim Weirich <jim (at) edgecase.com> 1790590242 +0000

Added main.py.

NOTA: Si definiste los alias ‘type’ y ‘dump’ en el lab de alias, puedes escribir git type y git dump en lugar de los comandos cat-file, más largos (que yo nunca recuerdo).

Este es el volcado del objeto commit que está en la cabeza de la rama main. Se parece mucho al objeto commit de la presentación anterior.

Encontrar el árbol

Podemos volcar el árbol (tree) de directorios al que hace referencia el commit. Debería ser una descripción de los archivos (del nivel superior) de nuestro proyecto (para ese commit). Usa el hash SHA1 de la línea “tree” mostrada arriba.

Ejecuta:

git cat-file -p <treehash>

Así es como se ve mi árbol…

Salida:

$ git cat-file -p 45e0479
040000 tree 315d7a3173ef77773f0d082dd0549832e9ff3a17	lib
100644 blob ab00241e61b023b4913091bf8d63d0b279dde3ef	main.py

Efectivamente, veo el archivo main.py y el directorio lib.

Volcar el directorio lib

Ejecuta:

git cat-file -p <libhash>

Salida:

$ git cat-file -p 315d7a3
100644 blob 78b32bd2ceff889d650552e47cd39fc49df0be5c	hello.py

Ahí está el archivo hello.py.

Volcar el archivo hello.py

Ejecuta:

git cat-file -p <rbhash>

Salida:

$ git cat-file -p 78b32bd
import sys

# Default is World
# Author: Jim Weirich (jim@somewhere.com)
name = sys.argv[1] if len(sys.argv) > 1 else "World"

print(f"Hello, {name}!")

Ahí lo tienes. Hemos volcado objetos commit, objetos árbol y objetos blob directamente desde el repositorio git. No hay nada más: blobs, árboles y commits.

Explora por tu cuenta

Explora el repositorio git manualmente por tu cuenta. Intenta encontrar el archivo hello.py original del primerísimo commit siguiendo manualmente las referencias de hash SHA1 a partir del último commit.
