lab 19 Modificar commits

Objetivos

  • Aprender a modificar (amend) un commit existente

Cambia el programa y haz commit

Añade al programa un comentario con el autor.

hello.py

import sys

# Default is World
# Author: Jim Weirich
name = sys.argv[1] if len(sys.argv) > 1 else "World"

print(f"Hello, {name}!")

Ejecuta:

git add hello.py
git commit -m "Add an author comment"

Vaya, debería incluir un email

Después de hacer el commit, te das cuenta de que un buen comentario de autor debería incluir un email. Actualiza el programa hello para que incluya un email.

hello.py

import sys

# Default is World
# Author: Jim Weirich (jim@somewhere.com)
name = sys.argv[1] if len(sys.argv) > 1 else "World"

print(f"Hello, {name}!")

Modifica el commit anterior

La verdad es que no queremos un commit aparte solo para el email. Vamos a modificar (amend) el commit anterior para que incluya el cambio del email.

Ejecuta:

git add hello.py
git commit --amend -m "Add an author/email comment"

Salida:

$ git add hello.py
$ git commit --amend -m "Add an author/email comment"
[main b8b311e] Add an author/email comment
 Date: Mon Sep 28 10:04:13 2026 +0000
 1 file changed, 2 insertions(+), 1 deletion(-)

Revisa el historial

Ejecuta:

git hist

Salida:

$ git hist
* b8b311e 2026-09-28 | Add an author/email comment (HEAD -> main) [Jim Weirich]
* 030f7aa 2026-09-28 | Added a comment (tag: v1) [Jim Weirich]
* e15e6ef 2026-09-28 | Added a default value (tag: v1-beta) [Jim Weirich]
* 067de2d 2026-09-28 | Using sys.argv [Jim Weirich]
* ad11021 2026-09-28 | First Commit [Jim Weirich]

Podemos ver que el commit original de “author” ha desaparecido y lo ha sustituido el commit “author/email”. Puedes conseguir el mismo efecto haciendo reset de la rama un commit hacia atrás y volviendo a hacer commit de los nuevos cambios.
